# Časovni načrt — 6 tednov

## Teden 1 — Analiza, načrtovanje, priprava okolja
- **Pajp (IS):** repo na GitHubu, Docker okolje, docker-compose.yml
- **Nal + Mitja:** specifikacija, ER diagram (≥4 tabele), wireframi (3 pogledi)
- **Vsi:** uvodni sestanek

## Teden 2 — Infrastruktura + PB
- **IS:** dokončanje docker-compose, veja `develop`, pravila za PR
- **Razvijalca:** SQL skripte, testni podatki (10 predmetov, 20 učiteljev, 100 učencev)

## Teden 3 — CRUD administrator + varnost strežnika
- **Razvijalca:** CRUD predmeti/učitelji/učenci, povezave
- **IS:** reverse proxy, HTTPS

## Teden 4 — Prijava + pogleda učitelja in učenca
- **Razvijalca:** avtentikacija, avtorizacija, pogledi učitelj/učenec, oddaja nalog
- **IS:** javna domena, pravice datotek, backup skripta

## Teden 5 — Testiranje, oblikovanje, dokumentacija
- **Vsi:** testni primeri, GitHub Issues
- **IS:** tehnična dokumentacija, diagram arhitekture
- **Razvijalca:** uporabniška navodila

## Teden 6 — Zaključno testiranje, predstavitev, oddaja
- **Vsi:** finalno testiranje, predstavitev, README, tag/release
