# Poročila

## Dnevna poročila
Vsak dijak zase piše sproti. Struktura mape:
```
porocila/
├── pajp/
│   └── 2026-09-14.md
├── nal/
│   └── 2026-09-14.md
└── mitja/
    └── 2026-09-14.md
```

Vsebina dnevnega poročila:
- **Datum**
- **Kaj sem delal**
- **Kaj sem dokončal**
- **Česa mi ni uspelo dokončati in zakaj**

## Tedenska poročila
Skupno, do pol strani. Datoteka: `porocila/teden-<n>.md`.
